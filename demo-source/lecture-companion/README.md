# مدار — مساعد المحاضرات

نسخة أولية محلية لتفريغ المحاضرات وربط التسجيل بصفحات PDF، ثم سؤال ChatGPT أو Gemini عن المحتوى مع إحالات للمصدر.

## التشغيل على Windows

1. افتح هذا المجلد في VS Code: `D:\Hermes\lecture-companion`.
2. شغّل `setup.bat` مرة واحدة. يحتاج Node.js 20+ وPython 3.10+؛ ينشئ بيئة مستقلة ويثبت `pypdf` و`faster-whisper`.
3. شغّل `run.bat`، ثم افتح `http://127.0.0.1:3000` إذا لم يفتح تلقائياً.
4. أول تفريغ ينزّل نموذج Whisper متعدد اللغات محلياً (الإعداد الافتراضي `small`؛ قد يكون التنزيل كبيراً ويستغرق وقتاً).

للتطوير: `npm start`، والاختبارات `npm run test:all`.

## مزودات الذكاء الاصطناعي المجانية

- **ChatGPT:** اضغط «تسجيل الدخول إلى ChatGPT». يستخدم التطبيق تدفق OpenAI الرسمي Sign in with ChatGPT لطلب موافقة مستقلة على استعمال حصة الحساب، ولا يخزن الجلسة إلا في ذاكرة التطبيق. أهلية الحساب المجاني والإتاحة الإقليمية تحددها OpenAI؛ إذا رُفضت الأهلية فلن يتحول التطبيق تلقائياً إلى API مدفوع.
- **Gemini:** يلزم إنشاء مفتاح Gemini API في [Google AI Studio](https://aistudio.google.com/apikey) من دون اشتراك. أدخل المفتاح من الإعدادات؛ يبقى في ذاكرة صفحة التطبيق ولا يُكتب إلى ملف. استخدم مشروعاً **من دون Cloud Billing** لتجنب الرسوم؛ الاستخدام المجاني محدود بحصص ومعدلات من Google وقد تتغير.
- لا يرسل التطبيق ملف الصوت إلى أي مزود: Whisper يفرّغه محلياً. عند التحليل/السؤال، يرسل **النص المستخرج من الصوت وصفحات PDF** إلى المزود المختار.

## الموجود حالياً

- رفع صوت (حتى 250 MB) وPDF (حتى 50 MB) ومعاينة التسجيل/الشرائح.
- تفريغ محلي بـWhisper مع الطوابع الزمنية واكتشاف تلقائي للغة.
- استخراج نص PDF محلياً مع أرقام الصفحات.
- ربط مقاطع الصوت والصفحات عبر موديل مختار، مع درجة ثقة لكل حدث.
- دردشة grounded على المحاضرة؛ استشهادات الصفحة والوقت قابلة للنقر.
- ChatGPT عبر موافقة OAuth رسمية، وGemini عبر مفتاح AI Studio المجاني.

## حدود نسخة MVP

- ملفات PDF المصورة التي لا تحتوي طبقة نص تحتاج OCR؛ النسخة الحالية تكشف الصفحات الفارغة ولا تعالجها بعد.
- مطابقة السلايد/الصفحة تقديرية وتعتمد على النص؛ الأحداث منخفضة الثقة تظهر بوضوح.
- الملفات المؤقتة تُحذف عند اكتمال المعالجة؛ ملفات الدراسة والمحادثة غير محفوظة بعد إغلاق الصفحة/التطبيق.
- التطبيق مربوط بـ`127.0.0.1` ولا ينبغي نشره على الإنترنت كما هو. لم يُبنَ بعد نظام مستخدمين أو تخزين مشفر لمفاتيح Gemini.
- تكامل ChatGPT يعتمد مسار Sign in with ChatGPT المفتوح للمطورين وقد تتغير أهلية الحساب أو قيود الخدمة؛ حدّث التطبيق وراجع شروط OpenAI.
